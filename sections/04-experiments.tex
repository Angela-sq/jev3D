\section{Experiments}
\label{sec:experiments}
\subsection{Experimental Setup}
We evaluate Claude Fable 5.1 (\texttt{claude-fable-5-1}) on 19 Minecraft
tasks in seven skill categories. The model sees only a $640\times360$
screenshot, the goal sentence, and elapsed game time, and replies with one
keyboard-and-mouse action per decision. The game keeps running while the
model thinks, with its previous action still applied, so slow decisions
cost game time. Each task runs once on one seed, with a cap of 100 model
calls per episode.

\subsection{Main Results}
Table~\ref{tab:results} lists successes per category. Fable passed
3 of 19 tasks. With one episode per task, these counts are a rough
picture rather than a precise success rate.
